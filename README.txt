STUDENT'S TO-DO LIST WEBSITE
============================

Theme colours: Navy #282B4A and Cream #EEEBDA

FILES
- index.html: Website structure
- style.css: Website styling and responsive layout
- script.js: Navigation, adding/deleting/completing tasks, and progress summary

HOW TO RUN
1. Extract student_todo_list_project.zip.
2. Open the student_todo_list_project folder.
3. Double-click index.html to open it in Chrome or another browser.

FEATURES
- Student name, age, and current learning topic
- Choose common student task categories
- Add tasks and optional due dates
- Mark tasks complete with a check mark
- Filter all, pending, and completed tasks
- Delete any task
- View task counts and completion percentage

NOTE
This is a front-end beginner project. Tasks work in the browser session; there is no database or server setup required.
